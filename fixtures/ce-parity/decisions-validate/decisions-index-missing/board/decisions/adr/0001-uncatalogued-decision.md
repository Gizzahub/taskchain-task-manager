# ADR-0001: uncatalogued decision

- Status: Accepted
- Date: 2026-09-29
- Owners: parity fixture

## Context

The document itself is fully valid.

## Decision

Keep it valid while dropping the README index table that catalogues it.

## Rationale

The index check must catch a lost catalogue even when every document is clean.

## Consequences

The README error names the documents that nothing catalogues any more.
